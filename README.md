# 🌿 Ayurvedic Website

A modern, responsive Ayurvedic website built with **Next.js**, **React.js**, **TypeScript**, and **Tailwind CSS**.  
The application provides an elegant UI with attractive banner images, an image slideshow, and a clean layout optimized for all devices.

---

## ✨ Features
- 📱 **Responsive Design** – Works seamlessly on mobile, tablet, and desktop.
- 🌿 **Modern UI** – Clean layout with **Tailwind CSS**.
- 🖼️ **Attractive Banner Images** – Engaging visuals to represent Ayurvedic treatments/services.
- 🎞️ **Image Slideshow** – Showcase treatments and services in a sliding gallery.
- 🎨 **Lucide React Icons** – Lightweight, customizable icons integrated throughout the website.
- ⚡ **Next.js & TypeScript** – Optimized, scalable, and strongly-typed React framework.

---

## 🛠️ Tech Stack
- **Next.js 15+**
- **React.js**
- **TypeScript**
- **Tailwind CSS**
- **Lucide React Icons**
